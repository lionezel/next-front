# Claude Code Context for NEXT-FRONT

Refer to [PROJECT_MEMORY.md](./PROJECT_MEMORY.md) for full architecture, design guidelines, business context, and deployment procedures.

## Quick Summary
- **App**: Next.js 16 with Turbopack, Tailwind CSS, Firebase Hosting (`next-ffca0`).
- **Brand**: NEXT Connection Group 360° (Planificación financiera, blindaje y protección patrimonial).
- **Core Verticals**: Finanzas, Seguros, Inversiones.
- **Twin Repo**: `next-admin` handles credit applications, underwriting, and staff backoffice.
- **Build & Test**: `npm run build`
- **Remotes**: `origin` (GitHub) & `azure` (Azure DevOps).
